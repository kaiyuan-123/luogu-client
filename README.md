# 洛谷桌面客户端（非官方）

把洛谷装进一个干净的小窗口：没有地址栏、标签页、书签栏，深色 / 浅色一键切换，窗口还能透出桌面。

> 这是个人做的第三方外壳，**和洛谷官方没有任何关系**，不包含、不分发洛谷的任何代码或素材。

![磨砂模式](docs/frost.png)

![纯透明模式](docs/clear.png)

## 特性

- **干净外壳**：单窗口、无地址栏 / 标签页 / 菜单栏；站内链接窗口内打开，站外链接交给默认浏览器。
- **深色模式**：顶栏右上角一键切换，按站点结构整块反色，图片保持原色，滚动时顶栏侧栏不会跑位。
- **背景透明 + 磨砂**：窗口背景半透明，能看到桌面；点半圆图标可在「纯透明 / 磨砂（亚克力）」之间切换，右边滑块调透明度。
- **全屏**：`F11` 或 ⛶ 进入，`Esc` 退出；全屏时窗口按钮整条隐藏。
- **导航按钮**：左上角 ‹ ↻ ›，配 `Alt+←` / `F5` / `Alt+→`。
- **去广告**：隐藏站内推广位，拦截常见广告 / 统计域名（请求层）。
- **本地优先**：登录态、缓存、窗口位置、透明度设置都只存在本机，不上传任何数据。

## 快速开始

需要 **Windows 10/11**（磨砂效果需要 Windows 11）。

```powershell
git clone https://github.com/<your-name>/luogu-client.git
cd luogu-client
powershell -ExecutionPolicy Bypass -File .\tools\install.ps1
```

脚本会：

1. 把 `app\` 复制到 `D:\LuoguClient`（D 盘不存在时用 `%LOCALAPPDATA%\LuoguClient`）；
2. 下载 Electron 运行时（约 150MB，走 npmmirror 镜像）；
3. 生成启动器 `启动洛谷.vbs`；
4. 在桌面创建「洛谷」快捷方式。

想装到别处：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install.ps1 -Target "E:\Apps\LuoguClient"
```

## 使用

| 位置 | 功能 |
| --- | --- |
| 左上角 `‹ ↻ ›` | 后退 / 刷新 / 前进（无历史时自动变灰） |
| 顶栏右侧 `☾ 夜间` / `☀ 日间` | 切换深色 / 浅色 |
| 顶栏右侧半圆图标 | 弹出「纯透明 / 磨砂」菜单 |
| 顶栏右侧滑块 | 背景透明度（0% 不透明 → 100% 最透） |
| 顶栏右侧 `⛶ — □ ✕` | 全屏 / 最小化 / 最大化 / 关闭 |

快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Alt + ←` / `Alt + →` | 后退 / 前进 |
| `F5`、`Ctrl + R` | 刷新 |
| `F11` | 进出全屏 |
| `Esc` | 退出全屏 |
| `Alt + Shift + D` | 切换深色 / 浅色 |
| `Ctrl + M` / `Ctrl + W` | 最小化 / 关闭窗口 |
| `Ctrl + +` / `-` / `0` | 缩放 / 还原 |

窗口操作：拖顶栏移动窗口，拖四条边 / 四个角调整大小。

## 去广告开关

`app/config.json`：

```json
{
  "hidePromos": true,
  "blockAds": true
}
```

- `hidePromos`：隐藏站内推广位（右侧「洛谷推荐」那一类）
- `blockAds`：拦截常见广告 / 统计域名

不想去广告就把对应项改成 `false`，重启客户端生效——代码里没有硬编码，完全由这个文件控制。

## 实现原理（简述）

- 用 Electron 加载 `https://www.luogu.com.cn/`，`frame: false` + `transparent: true` 做出无边框透明窗口；借洛谷自己的顶栏当拖动区域。
- 深色不是简单套一层反色滤镜：页面的顶层容器（顶栏 / 侧栏 / 内容区 / 弹层）各自 `filter: invert(1) hue-rotate(180deg)`，再把主题变量换成「反色前的浅色」，于是卡片、底色、边框都有层次；图片再反一次抵消，保持原色。
- 透明：把页面底色的 alpha 交给窗口底色和 CSS 变量，文字不参与透明；磨砂用 Windows 11 的 acrylic 材质由 DWM 模糊桌面。
- 兜底扫描：对少数没被规则覆盖的大块组件，扫描后统一换成同色 + 当前透明度。

## 已知限制

- 只在 Windows 上做过测试；macOS / Linux 能跑，但磨砂和透明效果没验证。
- 磨砂需要 Windows 11；Windows 10 上会自动退化成纯透明（没效果但不报错）。
- 站外链接、广告、部分第三方 iframe 保持原样。
- 洛谷改版后如果结构大变，深色覆盖可能需要跟着调整（`app/theme.css` 里有注释说明）。
